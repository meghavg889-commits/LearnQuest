# 🎮 LearnQuest

### AI-Powered Gamified Learning Platform

LearnQuest is an interactive learning web application designed to make studying more engaging through games, missions, quizzes, challenges, XP, stars and levels.

## 💡 Problem

Students often find it difficult to stay motivated while studying difficult topics. Traditional learning methods may also make it difficult to identify weak concepts and receive immediate feedback.

## 🚀 Solution

LearnQuest transforms study topics into an interactive game-based learning experience.

Students can:

- 📚 Choose a learning topic
- 🎯 Complete missions and challenges
- 🧠 Answer quizzes and questions
- ⭐ Earn stars and XP
- 🏆 Progress through levels
- 🔍 Identify weak topics
- 💡 Receive explanations for incorrect answers
- 🔥 Maintain a learning streak
- 📊 Track their learning progress through a dashboard

## ✨ Key Features

- Gamified learning
- Topic-based quizzes
- XP and star rewards
- Level progression
- Weak-topic identification
- Learning explanations
- Progress dashboard
- Daily streak system
- Multiple educational categories
- Simple and student-friendly interface
